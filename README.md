Manual QA Testing
text
Test Levels: Unit → Integration → System → Acceptance

Test Types: Functional | Regression | Smoke | Sanity | Exploratory | UAT

Bug Severity: Critical → Major → Minor → Trivial

Bug Priority: High → Medium → Low

STLC: Requirements → Planning → Design → Execution → Reporting → Closure
